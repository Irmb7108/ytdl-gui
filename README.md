# YouTube Downloader GUI

A modern GUI YouTube Downloader written in Python (PyQt6) and powered by `yt-dlp`.

## Features
- Modern dark theme interface
- Video (Best, 1080p, 720p) & Audio extraction (MP3, M4A, FLAC, OPUS)
- Anti-bot restriction bypass
- Browser cookies integration
- Persistent settings & download progress tracking
- Direct file playback & folder opening

## Requirements
```bash
sudo pacman -S python python-pyqt6 yt-dlp ffmpeg
